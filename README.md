# Machine Learning with Python

This repository documents my learning journey through IBM's Machine Learning with Python course on Coursera.
It contains practical exercises, Jupyter notebooks, implementations, and projects focused on understanding machine learning algorithms and applying them to real-world datasets using Python and Scikit-learn.

## Topics Covered

### 1. Introduction to Machine Learning
- Machine learning fundamentals and common types of learning algorithms
- The machine learning model lifecycle
- Machine learning roles and applications
- Python and the Scikit-learn ecosystem

### 2. Linear and Logistic Regression
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Non-Linear Regression
- Logistic Regression
- Training and testing regression and classification models

### 3. Supervised Learning Models
- Classification and Multi-Class Classification
- Decision Trees
- Regression Trees
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- Random Forests
- XGBoost
- Bias-Variance Tradeoff
- Ensemble Learning

### 4. Unsupervised Learning Models
- Clustering strategies and applications
- K-Means Clustering
- DBSCAN
- HDBSCAN
- Dimensionality Reduction
- Principal Component Analysis (PCA)
- t-Distributed Stochastic Neighbor Embedding (t-SNE)
- Uniform Manifold Approximation and Projection (UMAP)
- Feature Engineering

### 5. Model Evaluation and Validation
- Classification Evaluation Metrics
- Regression Evaluation Metrics
- Confusion Matrices
- Feature Importance
- Evaluation of Unsupervised Learning Models
- Cross-Validation
- Model Validation and Generalization
- Regularization in Regression and Classification
- Machine Learning Pipelines
- Hyperparameter Tuning with GridSearchCV
- Data Leakage and Common Modeling Pitfalls

### 6. Practical Projects
- Titanic Survival Prediction
- Rainfall Prediction Classification
- Data Cleaning and Feature Engineering
- Model Building, Evaluation, and Optimization

## Tools & Libraries
- Python
- Scikit-learn
- Jupyter Notebook
